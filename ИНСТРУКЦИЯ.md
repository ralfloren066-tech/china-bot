# 🤖 Poizon Tracker Bot — Инструкция

Бот с автопарсингом цены для Poizon, Taobao, 1688 и 95.
Если цену не удалось вытащить — спросит вручную.

---

## Что записывается в Google Sheets

| № | Дата | Источник | Ссылка | Название | Цена (¥) | Курс | Цена (₽) | Кол-во | Размер | Итого (₽) |

---

## Шаг 1 — Создай Telegram-бота

1. Открой [@BotFather](https://t.me/BotFather)
2. Напиши `/newbot` → придумай имя и username
3. Скопируй **токен**: `7123456789:AAFxxxxxxxxx`

---

## Шаг 2 — Узнай свой Telegram ID

Напиши [@userinfobot](https://t.me/userinfobot) — он пришлёт твой ID, например `123456789`

---

## Шаг 3 — Создай Google Таблицу

1. Открой [sheets.google.com](https://sheets.google.com) → создай новую таблицу
2. Скопируй **ID** из URL:
   ```
   https://docs.google.com/spreadsheets/d/ ВОТ_ЭТОТ_ID /edit
   ```

---

## Шаг 4 — Google Service Account (ключ доступа)

1. Перейди на [console.cloud.google.com](https://console.cloud.google.com)
2. Создай новый проект (кнопка вверху)
3. **APIs & Services → Library** → включи:
   - ✅ Google Sheets API
   - ✅ Google Drive API
4. **APIs & Services → Credentials → + CREATE CREDENTIALS → Service Account**
5. Задай любое имя → Done
6. Нажми на созданный аккаунт → вкладка **Keys → Add Key → Create new key → JSON**
7. Скачается JSON-файл — **открой его и скопируй всё содержимое**

---

## Шаг 5 — Дай боту доступ к таблице

1. В JSON-файле найди строку `"client_email"`, например:
   `poizon-bot@my-project.iam.gserviceaccount.com`
2. В Google Таблице нажми **Поделиться** → вставь этот email → роль **Редактор**

---

## Шаг 6 — Залей на GitHub

1. Создай репозиторий на [github.com](https://github.com/new)
2. Загрузи **4 файла**: `bot.py`, `parser.py`, `requirements.txt`, `railway.toml`
   - **Add file → Upload files** → перетащи все четыре → Commit changes

---

## Шаг 7 — Деплой на Railway

1. Зарегистрируйся на [railway.app](https://railway.app) через GitHub
2. **New Project → Deploy from GitHub repo** → выбери репозиторий
3. Открой проект → вкладка **Variables** → добавь:

| Переменная | Значение |
|---|---|
| `TELEGRAM_TOKEN` | Токен от BotFather |
| `SHEET_ID` | ID Google таблицы |
| `GOOGLE_CREDS_JSON` | Всё содержимое JSON-файла целиком |
| `ALLOWED_USER_ID` | Твой Telegram ID |

> ⚠️ `GOOGLE_CREDS_JSON` — вставь весь JSON как одну строку прямо в поле. Railway сохранит корректно.

---

## Шаг 8 — Проверь

1. Открой бота → `/start`
2. Отправь ссылку с Poizon / Taobao / 1688 / 95
3. Бот попробует сам найти цену
4. Если нашёл — покажет карточку и спросит кол-во/размер
5. Если не нашёл — спросит цену вручную
6. Нажми **✅ Сохранить** — строка в таблице

---

## Команды

| Команда | Что делает |
|---|---|
| `/rate` | Текущий курс ¥ → ₽ |
| `/setrate 14.50` | Задать свой курс |
| `/cbr` | Вернуть курс ЦБ РФ |
| `/list` | Последние 5 товаров |
| `/cancel` | Отменить текущий ввод |

---

## Честно о парсинге

| Сайт | Что парсится | Надёжность |
|---|---|---|
| Poizon / dewu.com | Название, иногда цена | ~40% |
| Taobao | Название, иногда цена | ~50% |
| 1688 | Название, иногда цена | ~50% |
| 95 | Название, иногда цена | ~30% |

Все эти сайты защищены от парсинга. Если цена не найдена — бот спросит вручную.
Это нормально и ожидаемо. Главное что название часто вытаскивается, и ты не тратишь время на его ввод.
